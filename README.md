# SMT5V 필드 및 전투 진동 모드 v0.5.6

전투 타격과 필드 이벤트에 게임패드 진동을 추가하는 **진·여신전생 V Vengeance**용 모드입니다. 게임의 사운드 옵션에서 진동을 켜고 끌 수 있습니다.

지원 환경

| 항목 | 확인된 환경 |
| --- | --- |
| 플랫폼 | Windows 64비트 / Steam판 |
| 게임 배포 버전 표기 | 1.0.3a |
| Steam Build ID | 17140961 |
| 모드 버전 | 0.5.6 |
| 실기 확인 패드 | Xbox 4세대 컨트롤러 | 닌텐도 스위치 Pro 컨트롤러 

진동 대상

- 전투의 일반 적중·피격, 크리티컬, 약점, 가드 상태의 피해
- 필드에서 적 심볼 공격, 아이템 상자 파괴, 적 심볼 접촉

회복·미스·무효는 적중 진동에서 제외합니다. 심볼 공격 직후 1초 이내에 이어지는 접촉 효과음은 중복 진동을 생략합니다. 모든 기술·맵·컷신의 개별 연출을 전수 검증한 것은 아닙니다.

## Windows에서의 설치

1. 게임을 완전히 종료합니다.
2. Steam에서 게임 설치 폴더 (SteamLibrary\steamapps\common\SMT5V) 를 엽니다.
3. 배포 모듈의 **`xinput1_3.dll`**, **`SMT5V-Haptics.ini`** 두 파일을 게임의 **`SMT5V/Project/Binaries/Win64/`**에 복사합니다. 기존 INI가 있다면 업데이트 시 보존합니다. 다른 모드의 `xinput1_3.dll`이 이미 있다면 덮어쓰지 마세요.
4. 컨트롤러를 연결하고 Steam에서 게임을 평소대로 실행합니다.

SMT5V/
└─ Project/
   └─ Binaries/
      └─ Win64/
         ├─ SMT5V-Win64-Shipping.exe  ← 기존 게임 파일
         ├─ xinput1_3.dll
         └─ SMT5V-Haptics.ini

**Windows에서는 파일명을 `xinput1_3.dll`로 유지하며, 별도 실행 옵션은 필요 없습니다.** `SteamDeck` 폴더의 `d3d11.dll`은 Windows 설치에 사용하지 않습니다.

## SteamDeck에서의 설치

1. 게임을 완전히 종료하고 Steam Deck의 데스크톱 모드로 전환합니다.
2. Steam에서 게임 설치 폴더를 엽니다. 내장 저장소와 microSD에 따라 절대 경로가 다르므로 Steam에서 설치 위치를 확인해주세요.
3. 배포 모듈의 SteamDeck 폴더 내 **`d3d11.dll`**, **`SMT5V-Haptics.ini`** 두 파일을 게임의 **`Project/Binaries/Win64/`**에 복사합니다. `SteamDeck` 폴더 자체가 아니라 그 안의 두 파일을 복사합니다. 기존 INI가 있다면 업데이트 시 보존합니다.

**다른 프로그램/모드의 `d3d11.dll`이 이미 있다면 덮어쓰지 마세요.** 이 안내는 다른 그래픽 프록시와의 병합 설치를 지원하지 않습니다.

```text
SMT5V/
└─ Project/
   └─ Binaries/
      └─ Win64/
         ├─ SMT5V-Win64-Shipping.exe  ← 기존 게임 파일
         ├─ d3d11.dll
         └─ SMT5V-Haptics.ini
```

4. 이전에 이 모드의 Windows용 `xinput1_3.dll`을 복사했다면 게임 폴더 밖으로 옮깁니다. 이 모드를 두 이름으로 동시에 로드하지 않습니다. 다른 모드의 DLL은 제거하지 마세요.
5. Steam의 게임 **[속성] → [일반] → [실행 옵션]**에 아래 한 줄을 입력합니다.

```sh
WINEDLLOVERRIDES="d3d11=n,b" %command%
```

모드 배포 파일은 DLL과 INI 두 개입니다. UE4SS·Lua·Python·빌드 도구·설치 스크립트는 실행에 필요하지 않습니다. 모드 자체는 C/C++ 런타임을 정적으로 포함하며, 게임 자체의 실행 필수 구성요소는 그대로 필요합니다.

모드는 시스템 XInput 1.3을 사용합니다. 로그에 `System32 xinput1_3.dll load failed`가 나타나면 [Microsoft DirectX End-User Runtimes (June 2010)](https://www.microsoft.com/en-us/download/details.aspx?id=8109)의 설치 상태를 확인해주세요.

`install-state.json`과 `VALIDATION.ko.md`는 게임 폴더에 복사할 필요가 없습니다. `install-state.json`은 개발 PC의 설치 관리 기록이므로 일반 배포에 필요하지 않습니다.

## 게임 내 설정

1. 타이틀의 **[옵션] → [사운드]**, 또는 인게임 **[메뉴] → [시스템] → [옵션] → [사운드]**를 엽니다.
2. 볼륨 항목 아래의 **[진동]**에서 ON/OFF를 선택합니다.
3. 옵션 화면을 나갈 때 **‘적용한다’**를 선택합니다.

선택 중인 값은 임시 값입니다. ‘적용한다’를 선택해야 실제 진동과 INI에 반영되며, 적용하지 않으면 기존 값을 유지합니다. 저장한 값은 재실행 후에도 유지됩니다. OFF는 자동 이벤트와 수동 시험 진동을 모두 중지합니다.

진동은 게임 창이 활성화된 동안 출력하며, 창 전환이나 컨트롤러 연결 해제 시 모드의 진동을 취소합니다. 게임 EXE·PAK·세이브 파일은 수정하지 않습니다.

## 선택 사항: 단축키

기본 사용은 게임 내 옵션만으로 가능합니다. 단축키는 게임 창이 활성화된 상태에서 동작합니다.

| 키 | 동작 |
| --- | --- |
| F4 | 효과음 규칙과 소리 추적 설정 다시 읽기 |
| F5 | 패드 연결 및 모드 상태를 로그에 기록 |
| F6 / F7 / F8 | 왼쪽 / 오른쪽 / 양쪽 모터 시험 |
| F9 | 현재 진동 중지, 자동 이벤트 0.5초 억제 |
| F10 | 연결된 패드가 여러 개일 때 다음 패드 선택 |
| Ctrl+Alt+F10 | 옵션 안에서는 임시 값 전환, 옵션 밖에서는 즉시 ON/OFF 저장 |

수동 시험은 약 35% 강도로 350ms 동안 동작합니다. F11은 모드에서 사용하지 않습니다.

## 로그와 문제 해결

실행하면 DLL과 같은 폴더에 `SMT5V-HapticsPoC.log`가 생성됩니다.

| 증상 | 확인 사항 |
| --- | --- |
| 진동 항목이 보이지 않음 | DLL이 `Project/Binaries/Win64/`에 있는지, 로그에 `loaded`와 `OPTIONS UI`가 기록되는지 확인합니다. |
| 진동이 없음 | 진동 ON을 적용했는지, 게임 창이 활성화됐는지 확인합니다. F5로 연결 상태, F8로 모터 출력을 시험할 수 있습니다. |
| `NO CONTROLLER` 또는 패드 미검출 | 연결과 Steam Input 구성을 확인합니다. 여러 패드 사용 시 F10으로 출력 대상을 바꿀 수 있습니다. |
| `GetState=OK SetState=OK`만 표시됨 | 함수 주소 획득 성공이며 실제 패드 검출 성공을 뜻하지 않습니다. `CONTROLLERS`와 `TEST`/`EVENT` 기록도 확인합니다. |
| 지원 실행파일 불일치 메시지 | 게임 업데이트 후 재검증이 필요합니다. |

문제 제보 시 Steam Build ID, 모드 버전, 패드 모델·연결 방식과 해당 실행 구간의 로그를 함께 알려주세요.

효과음 추적 로그가 필요 없으면 게임 종료 후 INI의 `[General]`에서 `TraceSounds=0`으로 바꾸고 재실행합니다. 진동 규칙에는 영향을 주지 않습니다.

## 업데이트 및 제거

- **업데이트:** 게임 종료 후 이 모드의 DLL을 교체하고 기존 INI는 보존합니다.
- **제거:** 게임 종료 후 이 모드의 `xinput1_3.dll`을 제거합니다. INI와 로그는 원하면 함께 제거할 수 있습니다.
